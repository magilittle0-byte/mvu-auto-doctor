## 产品边界

- [x] `<content>` 仍是本回合事实来源；医生不改写、截断或重生成正文，也不创建纠错 swipe。
- [x] 自动变量检查每回合只有一个主任务；手动与自动分开；旧任务、迟到、错误分支和旧 swipe 零写入。
- [x] 数据库继续独立读取 `<content>`；医生不读取数据库表、不等待数据库、不调用第三方 CRUD，也未恢复 `integrations/database-final-reply-bridge.js`。
- [x] 社交审计无效、超时、解析失败与 HTTP 失败均零写入，不执行关系回滚删除。
- [x] 论坛、连续性、人物、势力与环境属于可选后台功能，不阻塞正文、数据库或关键变量结算。
- [x] 自动医生只节制自身生成和注入的压力；正文已有过量威胁仅作为外部事实观察，不聚合、复制或升级。

## 医生闭环

- [x] 偶发许可证使用医生独立随机通道，不读角色卡骰池；完整身份不匹配、`continue` 与关闭状态零触发零写入。
- [x] 同对象/同世界状态防刷；好运真实持续且不自动惩罚；坏运受压力上限、最低可玩性与响应窗口约束。
- [x] 本地计费估算、价格、月账本、提醒和费用停用门已删除；旧字段原样保留但不使用。
- [x] 严格与轻量独立 API 通道分别使用可调 1—8 并发池，默认 2/4；同端点同密钥也按通道隔离，宿主当前连接与 Story Oracle 兼容路由仍固定串行。
- [x] 人物分片、关系二审、世界连续性与论坛共享轻量池；模型请求并发不绕过完整目标身份、取消、迟到零写入和持久化写入队列。

- [x] Actor Ledger v5 使用稳定 ID，支持未知身份揭示、异变谱系、生命周期、动态人格证据、人物约束、语义状态事实、最后语义行动和连续失败计数。
- [x] MBTI、九型、Tritype、依恋型和病娇等类型捷径不会进入长期人物档案；旧 v3 账本迁移时不凭空补齐新维度。
- [x] 玩家、系统、环境、旁白与群体不会误入人物池；死亡或已解决人物不会继续调度。
- [x] 实际玩家名从当前聊天上下文动态排除；旧的玩家依赖目标迁移为约束，不会冻结人物自己的调查、准备、联络、移动或资源行动。
- [x] 非等待行动必须包含明确意图和至少一项结构化状态变化；只走计时器、只复述摘要或空泛等待不算语义成功。
- [x] worker 全失败、超时或空结果会结算失败、累计沉默并公平轮转；重要/次要/背景人物分别受有界语义沉默上限保护。
- [x] 正文只有出现具体语义证据才消费世界注入；仅提到人物名、地点或泛化词不会误删幕后支线。
- [x] 接受的 `<content>` 只反向更新人物实际观察到的信息；隐藏内心、未传播事实和第三方候选不广播。
- [x] 人物行动按候选→身份/知识/时间/地点/资源/能力/因果/玩家主权校验→结算顺序执行。
- [x] 人物、势力、环境三通道可独立推进，共享医生自己的压力与注入预算。
- [x] `due=false` 只能保留或探索，不能世界结算；收据 ID 包含完整作用域。
- [x] 收据覆盖计划→执行→世界结算→注入→正文消费/保留，并绑定聊天、消息、swipe、生成与分支身份。
- [x] 玩家设置提供后台行动人数、次要人物探索槽、势力槽、环境槽、主动碰撞强度、恢复节奏、同场压力上限、同场首领上限与注入数量，并明确只控制医生后台模拟。
- [x] Gemini Pro 真实探针发现人物分片旧默认30秒超时；默认迁移为90秒、上限120秒，只迁移旧默认值，目标身份变化仍立即取消且迟到零写入。
- [x] Gemini 人物分片若且仅若返回“完整单层 JSON 代码围栏”，本地剥除围栏后再进入原严格解析；前后说明、非法 JSON、额外字段、证据越界和越权写入仍全部拒绝。
